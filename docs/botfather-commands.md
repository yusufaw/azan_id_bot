# BotFather Commands

List of bot commands to register with BotFather via `/setcommands`.

## How to register

1. Open a chat with [@BotFather](https://t.me/BotFather).
2. Send `/setcommands`.
3. Select this bot from the list.
4. Send the block below as a single message.

## Command list

Descriptions are in Indonesian since that's the bot's user-facing language.

```
tentang - Info tentang bot ini dan cara memberi dukungan
jadwal - Lihat jadwal salat hari ini sesuai lokasi Anda
pengaturan - Atur lokasi (provinsi dan kota/kabupaten)
notifikasi - Atur pengingat azan untuk tiap waktu salat
```
